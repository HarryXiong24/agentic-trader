# Daily reports / 每日报告

One file per trading day (`YYYY-MM-DD.md`). Each run appends its own bilingual section: the Trade run in the morning, the hourly checks and the closing check during the session, any manual check, the Research run in the evening (Sunday through Thursday), and the weekly review on Sunday.

每个交易日一个文件（`YYYY-MM-DD.md`）。每次运行都会追加自己的双语部分：早上的交易、盘中的每小时检查和收盘检查、手动检查、晚上的研究（周日至周四），以及周日的每周复盘。
